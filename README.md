# 💼 ProFIND - Website Tìm Việc Làm

## 📌 Giới thiệu

**ProFIND** là website tìm việc làm được xây dựng bằng HTML, CSS và JavaScript, nhằm kết nối ứng viên với các doanh nghiệp tuyển dụng một cách nhanh chóng và thuận tiện.

Dự án được thực hiện trong khuôn khổ môn **Lập trình Web** tại Trường Đại học Mở TP. Hồ Chí Minh.

---

## 🎯 Mục tiêu

- Xây dựng giao diện website tìm việc làm hiện đại.
- Áp dụng HTML5, CSS3 và JavaScript trong phát triển Front-end.
- Thiết kế website thân thiện với người dùng và responsive trên nhiều thiết bị.
- Rèn luyện kỹ năng làm việc nhóm và quản lý dự án.

---

## 🛠 Công nghệ sử dụng

- HTML5
- CSS3
- JavaScript (ES6)
- Bootstrap 5
- Font Awesome

## 🚀 Hướng dẫn chạy dự án

1. Tải source code hoặc clone repository.
2. Mở thư mục dự án bằng Visual Studio Code.
3. Cài đặt tiện ích **Live Server** (nếu chưa có).
4. Nhấp chuột phải vào `index.html` → **Open with Live Server**.
